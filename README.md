# Dualon Edtech - Official Static Website & KYSSO 2026 Portal

Official modern, high-performance static website for **Dualon Edtech Private Limited**, built according to the **Dualon Brand Guidelines 2026** and **Dualon Website Homepage Content Specification**.

---

## 🚀 Key Brand & Content Features

- **Brand Colors**:
  - **Aurora Mint** (`#33CB98`): Innovation & primary brand accent
  - **Galactic Violet** (`#9966FF`): Creativity, curiosity & space exploration
  - **Void Black** (`#181818` / `#0E0F13`): Deep cosmic background & high contrast
  - **Lunar Mist** (`#F2F2F2`): Pure text clarity & balanced contrast
- **Logo Symbolism**:
  - Sharp customized triangular letter **"D"** inspired by the **"Summer Triangle"** asterism (*Deneb, Vega, Altair*).
- **Core Sections Implemented**:
  1. **Top Pre-Launch Announcement**: Live KYSSO 2026 alert.
  2. **Hero Section**: *"Learn. Compete. Win."* — Kerala's premier CBSE Science & Mathematics platform.
  3. **KYSSO 2026 Pre-Launch Edition**: One-time pre-launch edition with fee structure (₹99 for Classes 1–4, ₹299 for Classes 5–12).
  4. **About Dualon App**: Monthly dual-curriculum (Syllabus-Aligned PDF + Frontier Enrichment PDF: Astronomy, AI, Robotics, Space, Genetics).
  5. **Interactive Class Explorer**: Filter curriculum & competition details across Classes 1 to 12.
  6. **3-Level Olympiad Progression**: School Level &rarr; District Level &rarr; State Level with prizes (Cash, Tablets, Laptops).
  7. **How It Works**: Dual workflow for KYSSO 2026 vs. Dualon App Subscription.
  8. **The 5 Pillars of Why Dualon**: Uncompromised Science & Math focus.
  9. **Brand Story: The Summer Triangle**: Connection to celestial exploration.
  10. **Pricing & FAQ**: Transparent ₹299/mo subscription with free annual Olympiad entry for 12-month subscribers.
  11. **School Partnerships Desk**: Turnkey CBSE test center enrollment & bulk desk.
  12. **Interactive Registration Modal**: Instant pre-registration for parents, students, and schools.

## 🛠️ Development & Build

```bash
# Navigate to the project directory
cd dualon-static

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
